# Batch D — German A1 text path

Original Karta prototype authoring; pending external pedagogical review. No Listening/Speaking content, external exam copying, AI grading, migration, manual deployment or configuration change.

## Lessons and lexical scope

Eight frozen lessons are authored, each with ten purposeful steps, genuine recall, bounded production and a fresh final observation. Titles, outcomes, consolidated skills and prerequisite DAG are unchanged. Step associations are narrowed to the dimensions actually practised.

- U9 L01: ordinary tiredness/help/time needs; reviewed haben/sein and war/hatte chunks. No diagnosis or medical knowledge grading.
- U9 L02: permitted versus forbidden actions, access updates, du and polite Sie instructions.
- U9 L03: invitations, acceptance, cancellation and a useful alternative including day/time/place.
- U9 L04: independently read a new service message, identify purpose/register and communicate the needed next step.
- U10 L01: fresh practice notices/offers, numbers, explicit/corrected facts, contextual meaning and relevance. No final-portfolio stimulus bank reuse.
- U10 L02: choose familiar structures from communicative intention, without grammar-topic labels or answer templates.
- U10 L03: fictional form and practical message are separate observations; a good form never substitutes for a message.
- U10 L04: purpose, reply, targeted revision and a concrete practice need. Reflection is not mastery evidence.

Controlled familiar vocabulary: help, time, tiredness, office, station/bank, course, ticket, table/chair, work/study and dates/times. Incidental notice words are glossed (warten, draußen, geschlossen, öffnet). No clinical, regulatory, complex workplace or new subordinate-clause requirement.

## Unit assessments

U9 Check A/B: nine items/groups — need, notice, permission, instruction, invitation/change, details, purpose, register, practical next step. U10 Check A/B: ten items/groups — reading, corrected fact, relevance, question, needed response, object, transfer, form, message, revision. Stable prototype/version-1 IDs and independent A/B family identities reuse existing assessment contracts. Both Checks require their own four actual historical lesson completions.

U9/U10 Challenges each have eight separately authored items per A/B family. Existing >=75% rule remains: 6/8 clears, 5/8 fails; alternate-family retries/cooldown are unchanged. Clearance affects recommendation only, never lesson milestones or Check evidence.

## CP3: two integrated independent sittings

`DE.A1.CP3.PROTOTYPE.1`, `CP3.FORM.A/B`, `CP3.FAMILY.A/B`. Each sitting has 14 tasks (two tasks per essential group), within the existing 16-task contract. A/B use different scenarios, information layouts and elicitation, not name substitutions. Neither sitting reuses lesson-final stimuli.

| Essential outcome                | Sitting A                                         | Sitting B                                               |
| -------------------------------- | ------------------------------------------------- | ------------------------------------------------------- |
| Personal information/form        | factual fields + introduction                     | reversed-field repair + changed person                  |
| Familiar people/objects/routines | person/object description + routine               | different description + routine correction              |
| Everyday reading/relevance       | excluded time + matching travel offer             | changed place + matching course offer                   |
| Time/place/requests/instructions | polite visitor instruction + arrival reply        | permission enquiry + du instruction                     |
| Practical message                | friend attendance message + help request          | staff constraint/alternative message + service enquiry  |
| Recent event/change              | earlier state + changed visit                     | two earlier events + changed destination                |
| Transfer/revision                | recent trip plus future help + time-only revision | constraint/future alternative + adjective-only revision |

Only elicited, deterministically graded task dimensions are credited. A correct form does not validate writing. No hints or answer reveal before submission. Raw answers are not retained in assessment history. Accuracy is secondary to the seven result groups.

## Exact final-completion policy

The projection is read-only and derived; there is no completion document or persistence schema change. It validates submitted owner/track/release/version/family/item-order/event provenance, excludes future-dated evidence and uses the latest accepted observation **per registered family**. A retry supersedes its own family's earlier observation only; failures in another family remain unresolved. Historical documents are never rewritten.

Completion requires all of the following:

1. All 40 authored lessons have real historical completion, and none is blocked/unavailable. A restarted lesson retains its actual historical milestone.
2. All ten Unit Checks and CP1/CP2/CP3 have accepted submitted records.
3. Both independent CP3 families provide complete correct observations for all seven essential groups. One family, partial coverage or strong reading never substitutes for a missing/failed message.
4. There are no unresolved latest-family assessment task failures across recorded Checks/checkpoints. This intentionally conservative prototype criterion also keeps unmapped atomic diagnostic gaps visible rather than inventing broad essential credit.
5. A real delayed alternate-family CP3 observation has occurred.

Reviewed explicit supplemental target mappings consume compatible Unit Check/CP1/CP2 evidence in its actual narrow scope. They can expose unresolved gaps but cannot replace either CP3 family's full integrated coverage. Unmapped atomic targets gain no essential-outcome credit. Any failing latest task still has an exact review link.

The UI shows `A1 text-learning path complete` only when all conditions hold; otherwise it lists missing lessons/Checks/checkpoints/sittings and named follow-up tasks. Every essential group shows Demonstrated / Follow-up needed / Insufficient evidence, with concrete review lessons and scoped observations. This is a text-learning milestone; Listening/Speaking and unrestricted writing remain outside it. No full CEFR certification claim.

## Delayed follow-up

Prototype interval policy: an alternate-family sitting must **start at least 24 hours after** a prior CP3 sitting finished. This is a transparent product criterion, not a claim that 24 hours scientifically establishes retention. Existing server-generated startedAt/finishedAt timestamps suffice; no scheduler or migration is added.

Same-session A/B can supply independent families, but delayed follow-up remains Pending and final completion remains blocked. Merely waiting after two same-session attempts does not supply a new observation. Historical valid delayed observations remain recorded when a later retry addresses a gap; the latest-family correctness requirement still applies independently. Future timestamps, invalid provenance, drafts and other owners do not supply delayed credit.
